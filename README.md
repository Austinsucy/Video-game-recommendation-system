Video game recommendation system using a weighted vector embedding approach. 
Basically, take game genre tags (e.g. co-op, shooter, strategy, simulation, roguelike, etc.) and any other characteristics/features we'd like and assign them numerical weights.
We can then apply perhaps k-means clustering and other machine learning algorithms to these weights to determine the similarness of games. 
I would ultimately like to visualize the similarities of games using a graph network or other similar diagrams/representations on a website.

* Tools: Python, PyTorch, scikit-learn, React and maybe some database.
