Tag Vector Lab: 1,000 games vs the full 89,618

The same pipeline run twice: once on the 1,000-game map dataset from main, once on every game in the March 2025 Steam snapshot (test/full-90k-database). Both runs use the long “About this game” text instead of the short blurb. Put a 1k method on one side and a 90k method on the other to see how a game's neighbours, map and clusters change when the pool is 90 times larger.

      Scores for every method and build

      Pairs: share of the 100 known-similar pairs in config/similar_pairs.yaml on Austin's branch (40 sequel pairs, 60 cross-studio pairs; commit 002ccc7). Pairs are matched by title; when the 90k data has several listings with one title (editions, bundles), the listing with the most tag votes is used where each game is in the other's top (mutual) or at least one way. Only pairs where both games have a vector count. Genre: mean Jaccard overlap of Steam genres with the top neighbours; random neighbours score on the 1k set. Map kept: share of each game's 15 true neighbours that are also among its 15 closest dots on the t-SNE map.

      How much do neighbour lists agree?

      Mean overlap of each of the 1,000 games' top 10 neighbours between two runs. 1.00 means identical lists. Click a cell to put that pair on sides A and B.

      How this was built

      Built by python -m pipeline.vector_lab from the pipeline's own code and config/map_config.yaml: each game's text is its long description (short description when that is empty), and the embedding model is all-MiniLM-L6-v2 at the pinned revision, run on the configured embedding device. It reads only the first 256 word pieces of each text. Every map uses the published map's scikit-learn t-SNE and K-Means, with collision spreading applied. Neighbours are the exact cosine top-k, computed in row blocks. Games with no vector, such as games with no Steam tags under the tag-only methods, are left off the map; semantic and hybrid_semantic include them while they have a description. The CON 3 cap of 1,100 games means none of this can be published as the real map.
